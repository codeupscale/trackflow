# Bug Reports — TrackFlow

Investigated defects across the desktop agent, web dashboard, and Laravel backend. Each file
documents symptom, scope, severity, root cause, evidence (`file:line`), and fix recommendation
or resolution summary.

> **Verdict on timer architecture (updated 2026-07-30):** superseded. The earlier verdict —
> that the sync layer needed targeted fixes rather than a redesign — held until the same class of
> defect kept recurring in new shapes. The shared root cause was structural: the desktop and the
> server were BOTH writers of the same time entry, reconciled after the fact. Reconciliation
> cannot be made correct in general, because when two writers disagree there is no information
> left to decide which is right. The refactor makes local SQLite the sole writer and the server a
> replica fed by a one-way upsert; ~1,200 lines of reconciliation were deleted rather than
> patched. See [offline-first-time-sync-refactor.md](offline-first-time-sync-refactor.md).
