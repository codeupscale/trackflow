# Employee profile edit blocked for Owner (wrong frontend permission key)

| Field          | Value                                                                                                                                                                                                                                                                                                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Status**     | ✅ FIXED (2026-07-07)                                                                                                                                                                                                                                                                                                                                                              |
| **Severity**   | P1                                                                                                                                                                                                                                                                                                                                                                                 |
| **Area**       | Web HR / employee profile                                                                                                                                                                                                                                                                                                                                                          |
| **Symptom**    | Owner (and org managers) viewing `/hr/employees/{id}` see a read-only profile — no **Edit Profile** button, no Notes tab, no document verify/delete — despite having the Owner role.                                                                                                                                                                                               |
| **Root cause** | Frontend gated admin UI on a **non-existent** permission key `employees.edit_all_fields`. Backend defines `employees.edit_profile` (scoped: `own` for employees, `organization` for owner/admin). `hasPermission('employees.edit_all_fields')` is always `false`, so `canEdit` was only true when viewing your own profile (`isSelf`).                                             |
| **Evidence**   | `web/src/app/(dashboard)/hr/employees/[id]/page.tsx:94` — `hasPermission('employees.edit_all_fields')`; `web/src/components/hr/EmployeeProfileSheet.tsx:79` — same; `backend/database/seeders/PermissionSeeder.php:62` — only `employees.edit_profile` exists; `backend/app/Policies/EmployeeProfilePolicy.php:42` — update uses `employees.edit_profile` at `organization` scope. |
| **Fix**        | Replace with `hasPermissionWithScope('employees.edit_profile', 'organization')` for full-field edit; use `employees.manage_documents` / `employees.manage_notes` for document and note admin actions.                                                                                                                                                                              |
| **Resolution** | Fixed on `develop` via `fix/employee-profile-permission-keys` (2026-07-07). Dev deploy only; production (`main`) unaffected. Also removed dead `reports.view_all` check in app-usage report (permission does not exist). |
